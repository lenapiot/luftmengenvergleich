Planvergleich – Kurzinfo

Version: 1.3

Das Tool enthält vier Module:

- Lüftung – Luftmengenvergleich
- Lüftung – Schemanummernkontrolle
- Heizung/Kälte – Nummernkontrolle
- Heizung/Kälte – Lastvergleich

Installation / Start

1. ZIP-Datei herunterladen.
2. ZIP vollständig entpacken.
3. Planvergleich.exe starten.

Wichtig:
Die EXE bitte nicht direkt aus der ZIP-Datei starten.

Es ist keine separate Installation erforderlich.

Bei Fragen, Fehlermeldungen oder auffälligen Ergebnissen bitte Rückmeldung geben und wenn möglich die verwendeten Eingabedateien bzw. einen Screenshot mitsenden.
